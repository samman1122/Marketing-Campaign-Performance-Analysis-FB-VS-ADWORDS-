# Marketing-Campaign-Performance-Analysis-FB-VS-ADWORDS-
📌 Overview

This project analyzes a full year of Facebook & ADWORDS Ads data to uncover patterns in conversions, cost efficiency, and time-based performance. The goal is to identify when campaigns perform best and how businesses can optimize ad spend for better ROI.

🎯 Objectives

Analyze conversion trends across days and months
Evaluate Cost Per Conversion (CPC) over time
Identify high-performing vs low-performing periods
Compare overall performance efficiency with AdWords
Generate actionable business insights\


🛠️ Tools & Technologies

Python
Pandas
Matplotlib
Jupyter Notebook


📈 Key Analysis Performed

1. Weekly Conversion Analysis
Grouped data by days of the week
Identified patterns in user engagement and conversion behavior
2. Monthly Conversion Trends
Aggregated conversions by month
Detected seasonality and peak performance periods
3. Cost Per Conversion (CPC)
